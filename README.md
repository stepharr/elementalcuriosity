# Elemental Curiosity

Source for [elementalcuriosity.com](https://elementalcuriosity.com). It's a Jekyll site that GitHub Pages builds automatically whenever something changes on `main`.

## Writing

Open [Pages CMS](https://app.pagescms.org), choose this repo, and use **Posts** to write, edit, or unpublish. Saving commits to `main`, and the site updates about a minute later.

## Files

- `_posts/` holds the posts, one Markdown file each, named `YYYY-MM-DD-slug.md`.
- `about.md` is the About page.
- `_config.yml` sets the site title, tagline, and author.
- `_layouts/` and `assets/css/style.css` control the design.
- `.pages.yml` configures the CMS.
